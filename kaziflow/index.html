What changed
Build 7 keeps the startup fix from Build 6 and adds an internal review route so you can open the worker or employer side without waiting for SMS verification. It also improves Kenyan-number validation, adds a visible resend countdown, and fixes the backend logic that could incorrectly start the one-minute resend lock after an SMS delivery failure.

SMS OTP status
The live API is currently returning a delivery failure from the SMS-provider path. The review buttons do not bypass a real account: they create a temporary local preview only, so live applications, hiring actions and other protected backend actions remain unavailable until SMS delivery is repaired.

To review the app: choose whether you want to find work or hire, continue to the phone-verification screen, then use Preview worker or Preview employer. Relaunching the app returns you to normal onboarding.
